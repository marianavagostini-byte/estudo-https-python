# HTML study exercises

Exercises written while following Dave Gray's HTML course, plus a small multi-page recap site. The repository name comes from its first commits (notes on HTTPS basics); the current content is HTML and CSS.

## Folders

| Folder | Content |
|---|---|
| `estudo-html/` | Course exercises: semantic structure (`header`, `nav`, `main`, `section`, `article`, `footer`), links, images and `figure`, lists, a table, and forms with `fieldset`, inputs, `select` and `textarea` (submitted to the httpbin.org test service) |
| `projeto-recapitulacao/` | "The Little Taco Shop" recap project: three linked pages (home, hours, contact form) styled with an external CSS file |

## Running locally

No dependencies: open any `.html` file in a browser, or use a static server such as the VS Code Live Server extension.

## Status

Learning project. Example content (names, phone numbers, e-mail addresses) is placeholder text from the course.
